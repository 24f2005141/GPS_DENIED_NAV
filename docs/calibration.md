# Calibration and validation procedure

No physical calibration values were measured during this work. `config/real.yaml` defaults to `calibration_valid: false`, both scales zero, no smoothing, and no deadband. This prevents raw counts from being labelled metres.

1. Record the actual sensor model, mount orientation, ground surface, lighting, sensor height, and a measured reference distance. Attach the UART and capture time-stamped raw packets at rest and during controlled translations in body +X and +Y, then rotations in place. Confirm checksum and byte order against observed signs and magnitudes.
2. Determine whether each packet is integrated flow, pixel displacement, angular flow, or another quantity. If it is optical angular flow, measure ground distance and account for body rotation using gyro data. A fixed `m/count` scale may be valid only at one documented height and surface; use a range-dependent model if height changes.
3. Use a tape or other independent position reference. For repeated, straight body-axis trials, estimate `scale_x = reference_x / sum(raw_x)` and similarly for Y after sign and rotation checks. Calculate endpoint and trajectory errors on trials held out from calibration. Record every raw count, reference displacement, height, quality, and timestamp.
4. Sweep quality thresholds with good and poor surfaces; set `minimum_quality` based on rejection/error evidence. Measure stationary count noise before choosing a deadband. `smoothing_alpha` must remain 1 for metric output: smoothing displacement increments can move counts into later samples and rotate them under a different heading. The preprocessing node now disables `metric_valid` for nonunity alpha. Design and validate a time-aware filter separately if one is needed.
5. Identify the physical IMU model/interface and axis convention. Measure gyro bias while stationary. Establish initial yaw relative to East with an independent heading reference; set `heading_offset_deg` and only then `heading_reference_valid=true`. Verify quaternion frame and positive yaw covariance; a gyro alone drifts. A magnetometer, if present, requires hard/soft iron calibration and interference testing.
6. Enable `calibration_valid`, enter positive scale magnitudes and `invert_x/invert_y` signs, set `rotation_offset_deg`, and repeat independent validation. Do not reuse simulation's 0.01 m/count constant for real hardware.

Calibration report template: date, sensor ID/firmware, mounting diagram, height range, surface/light, byte order, raw log path, reference method, computed scales, axis signs, quality distribution, held-out endpoint and trajectory error, and uncertainty. All fields are currently **not measured** for real hardware.
